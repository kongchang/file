เปิดไฟล์นี้โดยตรงไม่ได้

หน้านี้ว่างเปล่าเพราะเปิดไฟล์ผ่าน file:// โดยตรง (ดับเบิลคลิกไฟล์) เบราว์เซอร์จะไม่ยอมรันสคริปต์หลักของระบบในกรณีนี้ ทำให้หน้าจอไม่แสดงอะไรเลย

วิธีแก้ (เลือกวิธีใดวิธีหนึ่ง):
1) เปิดผ่าน "Live Server" ใน VS Code
2) เปิด Command Prompt ที่โฟลเดอร์นี้ แล้วรัน python -m http.server จากนั้นเข้า http://localhost:8000
3) หรือ deploy ระบบขึ้น Firebase Hosting แล้วเปิดผ่านลิงก์เว็บไซต์จริง (แนะนำที่สุดสำหรับใช้งานจริง)
